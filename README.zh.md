界面是俄文。没有账号。词和评分留在这台浏览器里，也可以打包成文件带走。

## 用来做什么

给通过俄语学中文的人一个安静的地方：今天学什么，字怎么写，还记不记得。它不是信息流，也不是排好课的课程。词表和等级自己选，下次复习跟着你的回答走。

等级用来筛学习和测验。词表决定哪些词在用。点开一个词表，就能看到里面的词。

## 里面有什么

**词。** HSK 1–6 词表，5456 个词，另有短主题：问候、数字、食物、一天、动物、量词、句子、不同读音。自己的词表可以新建、改名、删除。删掉的词表里，词会留在「Мои слова」里。搜索认汉字、俄语和拼音，声调可有可无：`shui`、`shuǐ`、`shui3`。新词可以在 BKRS 词典里查到，再存到合适的等级。

**学习。** 四种评分：忘记、吃力、记得、轻松。下次出现是 1、3、7、14、30 或 60 天之后。每天的新词数量可以限住。按键 1–4 评分，5 朗读。

**测验。** 汉字和翻译双向、拼音、听音、例句、挖空、语法规则，以及一分钟速度题。例句和挖空只用你选中的词表，不掺别的表。

**语法。** 81 条短规则，按 HSK 1–6。每条有例句、拼音和俄语翻译。已经懂的规则可以标出来，测验就不再抽它。

**书写。** 笔顺可以看，也可以自己描。另有一组练习，用拼音或汉字把词打出来。笔画旁边有读音和释义。

**声音和外观。** 卡片和例句可以听：先是服务器语音，再是词典录音，然后是设备语音。卡片上的拼音只是标注，不拿去控制读音。主题有浅色、深色、青玉、纸、墨。声调可以上色：一声蓝，二声绿，三声橙，四声紫。

**进度。** 连续天数、今天答了多少、学会多少、还在学多少。按等级看一份，按词表再看一份。

## 数据放在哪里

词、自建词表、评分和设置都在浏览器里。设置里可以下载 JSON，换一台设备再打开。

三件事需要网络：查 BKRS、服务器语音，以及打开书写时的笔顺图。页面加载之后，卡片本身在本地读。

## 在自己的电脑上运行

需要 Node.js 22。

```bash
npm ci
npm run dev
```

应用在 `http://127.0.0.1:5173`。这个模式下，词典和语音从同一个地址回答。

```bash
npm run check
npm run build
```

`check` 跑项目自己的检查。`build` 做类型检查并生成页面。
