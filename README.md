<h1 align="center">Свои слова</h1>

<p align="center">
  Личное приложение, чтобы учить китайские слова с русским переводом.<br>
  Карточки, списки HSK, тесты, грамматика и порядок черт.
</p>

<p align="center">

Карточка выглядит так: иероглиф, чтение, смысл.

| | |
| --- | --- |
| **水** | shuǐ |
| | вода |

Интерфейс на русском. Аккаунт не нужен. Слова и оценки остаются в этом браузере, их можно забрать с собой файлом.

## Для чего

Приложение для того, кто учит китайский по-русски и хочет один спокойный набор: что учить сегодня, как записать слово своими руками и как проверить, что оно ещё помнится. Это не лента и не курс с уроками по расписанию. Вы сами выбираете списки и ступень, а повтор подстраивается под ответ.

Уровень отсекает ступень в учёбе и тестах. Список выбирает, какие слова вообще в ходу. Нажатие на список открывает его слова.

## Что внутри

**Слова.** Списки HSK 1–6, 5456 слов, и короткие темы: приветствия, числа, еда, день, животные, счётные слова, фразы, разные чтения. Свою подборку можно создать, переименовать и удалить. Слова удалённой подборки остаются в «Моих словах». Поиск понимает иероглиф, русский перевод и пиньинь, в том числе без тонов: `shui`, `shuǐ`, `shui3`. Новое слово можно найти в словаре БКРС и сохранить на нужную ступень.

**Учёба.** Четыре оценки: не помню, с трудом, помню, легко. Следующий показ через 1, 3, 7, 14, 30 или 60 дней. Число новых слов в день можно ограничить. Клавиши 1–4 ставят оценку, 5 произносит слово.

**Тесты.** Иероглиф и перевод в обе стороны, пиньинь, слово на слух, фраза, пропуск в примере, грамматическое правило и минута на скорость. Фраза и пропуск берут примеры только из выбранных списков и не подмешивают чужие.

**Грамматика.** 81 короткое правило по ступеням HSK 1–6. У каждого есть пример, пиньинь и русский перевод. Понятное правило можно отметить, и оно не попадёт в тест.

**Письмо.** Порядок черт можно посмотреть и обвести самому. Отдельно есть набор, где слово вписывают пиньинем или иероглифами. Рядом с чертами видны чтение и перевод.

**Голос и вид.** Карточку и пример можно послушать: сначала голос сервера, затем запись словаря, затем голос устройства. Пиньинь на карточке — подпись, он не управляет произношением. Темы: светлая, тёмная, нефрит, бумага, тушь. Тоны можно красить: первый синий, второй зелёный, третий оранжевый, четвёртый фиолетовый.

**Прогресс.** Серия дней, ответы за сегодня, сколько слов выучено и сколько в работе. Отдельно по ступени и отдельно по каждому списку.

## Где лежат данные

Слова, свои подборки, оценки и настройки хранятся в браузере. В настройках их можно скачать JSON и открыть на другом устройстве.

Сеть нужна для трёх вещей: поиск в БКРС, серверный голос и рисунок черт, когда открыт раздел письма. Сами карточки после загрузки страницы читаются на месте.

## Как запустить у себя

Нужен Node.js 22.

```bash
npm ci
npm run dev
```

Приложение откроется на `http://127.0.0.1:5173`. В этом режиме словарь и озвучка отвечают с того же адреса.

```bash
npm run check
npm run build
```

`check` гоняет внутренние проверки. `build` проверяет типы и собирает страницу.
